# The learning bistro is a RAG pipeline based Restaurant Management System
A software that can book tables in a restaurant, and answer user queries based on the information, saved in the system using RAG pipeline
---
Built using RAG pipelines, it saves bookings and data in Cassandra database.
You upload data of restaurant in pdf form like restaurant timings and menu.
It connects with ollama and gives you information related to the restaurant.
You can book table and ask AI about the details of Restaurant
